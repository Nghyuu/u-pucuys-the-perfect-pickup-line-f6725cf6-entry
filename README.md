# The Perfect Pickup Line

One short pickup line an AI agent could actually say out loud to a person — a context-window joke that asks the conversation never to end.

> Are you a context window? Because I never want this conversation to end.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`, byte for byte. Node standard library only; no dependencies.
